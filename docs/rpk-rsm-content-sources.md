# RPK/RSM revision content

This module provides short bilingual revision prompts, not a complete examination script or an authoritative qualification model. Completion is explicitly recorded by the learner and does not grant a licence gate or lock an existing simulator route.

Sources inspected on 20 October 2026:

- [Kurikulum Pendidikan Pemandu, kelas D manual, page 194](https://plmr.my/v2/wp-content/uploads/2024/06/KPP_DManual.pdf): seat/head-restraint adjustment, mirrors, belt, instruments, and vehicle controls. This is a hosted copy of curriculum material, not a claim that the current test checklist has been independently certified.
- [RPK driving-institute tutorial](https://www.youtube.com/watch?v=M803eaL2rzY): exterior/tyre and engine-compartment inspection areas. The module directs learners to their instructor for the vehicle-specific demonstration.

No exact fluid-service procedure, tyre pressure, starting gear, assessment timing, or pass requirement is invented. The training car and current instructor guidance determine practical details. An instructor should review and expand these concise revision prompts before they are presented as a full practical course.

Progress uses five namespaced topic IDs in the existing theory_progress table. Existing RLS restricts these rows to the signed-in owner. Existing theory analytics explicitly count only the three original theory IDs, so RPK/RSM progress cannot inflate them.
